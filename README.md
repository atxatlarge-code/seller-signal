# Property Distress Scorer

This app allows users to upload a main property list and cross-reference it against multiple distress lists (Tax Delinquency, Probate, etc.).

## How to use:
1. Upload your primary CSV.
2. Upload one or more "distress" CSVs.
3. Download the prioritized list based on match scores.

## Requirements:
- Python 3.x
- Streamlit
- Pandas
